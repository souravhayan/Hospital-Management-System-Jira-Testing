# Hospital-Management-System-Jira-Testing

## Project Overview
Manual testing was performed on a Hospital Management System developed using PHP and MySQL. The project includes structured test case execution, bug reporting, retesting, and Jira-based issue tracking across multiple functional modules.

## Main Project Repository
Source code of the Hospital Management System project:

🔗 https://github.com/souravhayan/Hospital_Management_System

## Live Project
🔗 https://hms.page.gd/

## Project Description
Created and executed 64 manual test cases covering functional, boundary value, and negative testing scenarios across 7 modules of the Hospital Management System. Identified, reported, and tracked 6 defects using Jira while monitoring issue status, retesting fixes, and maintaining testing progress throughout the testing lifecycle.

## Testing Scope
- Login & Authentication
- Department Management
- Doctor Management
- Patient Management
- Appointment Scheduling
- Medical Records
- Billing

## QA Activities

Multiple defects were identified, reported in Jira, and retested after fixes to ensure system stability and functionality.
