# Hospital-Management-System-Jira-Testing

## Project Overview
Manual testing performed on a Hospital Management System developed using PHP & MySQL. The project includes structured test case execution, bug reporting, retesting, and Jira-based issue tracking across multiple functional modules.

## Project Description
Created and executed 64 manual test cases covering functional, boundary value, and negative testing scenarios across 7 modules of the Hospital Management System. Identified, reported, and tracked 6 defects using Jira while monitoring issue status, retesting fixes, and maintaining testing progress throughout the project lifecycle.

## Testing Scope
- Login & Authentication
- Department Management
- Doctor Management
- Patient Management
- Appointment Scheduling
- Medical Records
- Billing

## QA Activities

## Conclusion
The Hospital Management System was tested across all major functional modules to validate application behavior, form validation, CRUD operations, authentication flow, and user access control. Multiple defects were identified, reported in Jira, and retested after fixes to ensure system stability and functionality.
